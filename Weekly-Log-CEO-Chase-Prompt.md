# Weekly Log — "Chase Down Each CEO" Prompt

Paste this into **each** CEO / worker chat (Island House, Software Development, Globe, Sancler, Sancler Property, House of Culture, Globe Bob / Tech Guy / content crew, Mererid, etc.) to get that thread's week in a consistent shape. Collate the replies into the company-wide report for Steve and Phil.

---

## The prompt (copy from here)

```
Give me your work report for this week, Monday 27 to Friday 31 July 2026.

Format: a short DAY-BY-DAY NARRATIVE. For each of the five days, in a few sentences:
- what you worked on that day,
- what you actually produced, shipped, or decided,
- an estimate of active time spent,
- anything still open, blocked, or waiting on someone.

Then finish with:
- "Week in one line" — a single sentence summary,
- "Top 3 highest-value things" this week (what I'd show a top boss),
- "Next week" — the 1–3 things you'll pick up.

Keep it honest and specific — real outputs, not activity for its own sake. If a day had no work, say so. This is going into a company-wide weekly report for Steve and, above him, Phil.
```

---

## How to run it
1. Open each CEO/worker chat and paste the block above.
2. Save each reply (or tell Jarvis and I'll collate them).
3. I merge them into one **Weekly Company Report**, de-duplicated and grouped by business, with the "highest-value" items pulled to the top for Phil.

*Tip: the "Top 3 highest-value things" line from each CEO is exactly the raw material for the Phil overview — it self-populates the boss-level summary.*
